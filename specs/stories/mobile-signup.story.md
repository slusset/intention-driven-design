# Story: Mobile Signup

As a trade-show prospect,
I want to create an account from my phone in under one minute,
So that I can continue the booth conversation without friction.

## Acceptance cues

- Signup form only requests essential fields.
- Successful submission returns an account identifier and next-step guidance.
