# Privacy Policy

**Intention Driven Design (IDD) Plugin**
**Effective Date:** March 3, 2026

## Overview

The Intention Driven Design plugin is an open-source Claude Code plugin licensed under the MIT License. It operates entirely within your local development environment.

## Data Collection

This plugin does **not** collect, store, transmit, or process any personal data. Specifically:

- **No telemetry or analytics** — The plugin sends no usage data to any external service.
- **No network requests** — The plugin makes no outbound network calls. All operations are local.
- **No accounts or authentication** — The plugin requires no sign-up, login, or API keys.
- **No cookies or tracking** — The plugin uses no browser-based tracking mechanisms.

## Artifacts Created

All artifacts generated by the plugin (specs, models, contracts, feature files, etc.) are written to your local project directory. They never leave your machine unless you choose to commit and push them to a remote repository.

## Third-Party Services

This plugin does not integrate with or send data to any third-party services. It runs as a set of skill definitions interpreted by your local Claude Code agent.

## Changes to This Policy

Updates to this policy will be reflected in this file within the project repository. The effective date at the top of this document will be updated accordingly.
